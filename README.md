# Gen-Z Spending Pattern Analysis

## Project Overview
A research and machine learning project analysing the spending behaviour
of Gen-Z individuals aged 18–25 using questionnaire-based primary data.

## Objectives
- Analyse spending behaviour among Gen-Z respondents
- Identify major spending priorities
- Categorise respondents into four spender types
- Examine financial awareness and saving behaviour
- Build a machine learning model to classify spender types

## Dataset
Primary data collected through a structured Google Forms questionnaire.

Current dataset: 254 respondents.

## Spender Categories
- Impulsive
- Balanced
- Planner/Saver
- Frugal

## Methodology
1. Questionnaire design
2. Primary data collection
3. Data preprocessing
4. Label encoding
5. Exploratory Data Analysis
6. Scoring and spender categorisation
7. Train-test split
8. Model training
9. Model evaluation
10. Comparative analysis

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation
Models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Multiple random train-test splits

## Key Finding
Random Forest demonstrated the strongest performance among the
three evaluated classification models in this study.
